# Программа «ERA Админка» для Windows

Папка `desktop/` — программа на Electron. Внутри открывается та же онлайн-админка
(`https://eradent.vercel.app/admin`), поэтому записи, врачи, услуги и фото общие с сайтом, телефоном и
браузером. Онлайн-админка продолжает работать как раньше.

- **Пароль один раз.** Вход хранится в профиле программы 60 дней и продлевается при каждом
  открытии — если пользоваться хотя бы раз в два месяца, пароль больше не спрашивается. «Выйти» в
  админке сбрасывает вход.
- Ссылки «Открыть сайт», WhatsApp и телефон открываются в браузере / WhatsApp / программе звонков.
- Без интернета показывается экран «Нет подключения», программа подключается сама, когда сеть появится.
- Alt — меню: обновить (Ctrl+R / F5), масштаб (Ctrl + / Ctrl −), во весь экран.
- Обновлять программу не нужно: всё новое в админке появляется само после деплоя сайта.
  Пересобирать установщик нужно, только если поменялся адрес сайта или сама оболочка.

## Установка на компьютер клиники

1. GitHub → репозиторий → **Releases** → последний «ERA Админка» → скачать `ERA-Admin-Setup-*.exe`
   (https://github.com/adolfsta1in/era/releases).
2. Запустить. Программа без платной подписи, поэтому Windows покажет «Windows защитила ваш компьютер» →
   **Подробнее** → **Выполнить в любом случае**. Это один раз, при установке.
3. На рабочем столе и в «Пуске» появится «ERA Админка». Открыть, ввести пароль админки — всё.

## Новая версия установщика

Собирается на Mac (или Windows) одной командой — подпись и Wine не нужны:

```bash
cd desktop && npm install
# поменять "version" в desktop/package.json, затем:
npm run dist                      # → desktop/dist/ERA-Admin-Setup-<версия>.exe
gh release create desktop-v<версия> dist/ERA-Admin-Setup-<версия>.exe --title "ERA Админка <версия>"
```

На Apple Silicon используется набор NSIS `1.2.1` (задан в `build.toolsets` в `desktop/package.json`) —
старый набор electron-builder там не запускается. Если сменился адрес сайта — поменяйте `ADMIN_URL`
в `desktop/main.js` и пересоберите.

## Запуск для разработки (Mac/Windows)

```bash
cd desktop && npm install
ERA_ADMIN_URL=http://localhost:3000/admin npm start   # или без переменной — живой сайт
```
